# OrbitTE C library

`libtent` exports the Mooncake v0.3.14 TENT C transfer-engine ABI. Install the
header, shared library and static library with `scripts/install-c-api.py` from
the OrbitTE source tree. See the [C API guide](https://github.com/OrbitInfra/OrbitTE/blob/main/docs/c-api.md)
for permissions, buffer lifetimes, status codes and a TCP example.
